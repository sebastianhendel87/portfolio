Tipografía: Monument Grotesk (Dinamo)

Para que se vea en el sitio, colocá aquí los archivos de la fuente:

  - MonumentGrotesk.woff2     (variable o Regular)
  - MonumentGrotesk-Italic.woff2  (opcional, para cursivas)

Podés comprar o licenciar la fuente en:
  https://abcdinamo.com/typefaces/monument-grotesk

Si tenés la variable font, un solo .woff2 basta para todos los pesos (100–900).
